# Live Bar — tài nguyên gốc từ tiktok-live-bar

Các file trong thư mục này được lấy nguyên từ <https://github.com/cherry9001/tiktok-live-bar>
(commit `e7d5270f1f923c81ae77f2c2ed53887cd5c88177`). Dự án đó phát hành dưới giấy phép MIT, xem `UPSTREAM_LICENSE`.

| File | Nguồn trong repo gốc | Ghi chú nguồn gốc |
|---|---|---|
| `characters/*.gif` (33 file) | `TikTokBridge/assets/gifs/` | `characters/SOURCES.json` (bản gốc ghi lại): phần lớn từ Weibo, không kèm giấy phép riêng |
| `dj/Megan_DJ.fbx` | `UnityProject/Assets/Resources/DJ/Megan_DJ.fbx` | Nhân vật + điệu nhảy Mixamo (Adobe): được dùng trong dự án, không được phân phối lại file gốc như một tài nguyên riêng lẻ |
| `sfx/fireworks.mp3` | `UnityProject/Assets/Resources/Audio/dragon-studio-fireworks-07-419025.mp3` | Bản gốc không ghi nguồn; tên file giống định dạng thư viện âm thanh Pixabay (chưa xác minh được) |

Live Bar dùng các file này làm **mặc định**. Trong tab Live Bar có thể đổi sang nhân vật / DJ vẽ bằng code, tiếng pháo hoa tự tổng hợp, hoặc file của bạn.

> Trước khi phát live thương mại, hãy tự kiểm tra quyền sử dụng các tài nguyên trên. Muốn bỏ hẳn: xoá thư mục tương ứng; Live Bar tự quay về bản vẽ bằng code.
